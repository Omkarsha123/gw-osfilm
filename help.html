How Frameflow works

A quick reference for running photo and video production in this workspace.

Getting started

  1. Create a project from All projects → New project. Give it a name, type, event date, and location.
  2. Open the project to manage its photo flow, video flow, tasks, and vendor assignments.
  3. Use Vendors to register design, printing, editing, and backup partners before assigning them to a project.
  4. Use Users to invite teammates and control what they can do with roles.

Photo flow

Click any stage in the timeline to mark the project's current stage. Toggle Album required? to switch between the 7-stage album workflow and the shorter 4-stage no-album workflow.

Video flow

Each deliverable moves through Not started → Data backup → Editing → Review → Complete. Use Advance status to move a deliverable forward, and the editor button on each card to assign who is cutting it.

Keyboard shortcuts

  • Ctrl + KOpen project search
  • EscClose the open dialog, popover, or menu
  • TabMove between fields inside an open dialog

Frequently asked questions

How do I create a new project?

Go to All projects in the sidebar, select New project, fill in the name, type, date, and location, then submit. You will land directly on that project's dashboard.

Where is my data stored?

Everything is stored in a local SQLite database on the server (data/frameflow.db) so it survives restarts.

Can I export a project?

Open a project and select Export project in the top-right of the page heading to download its full data as JSON.

How do I change the studio name?

Go to Settings from the sidebar and update the studio name and workspace label.
